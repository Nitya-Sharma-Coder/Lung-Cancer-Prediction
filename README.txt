# Lung Cancer Prediction — Streamlit starter

## Setup
1. Put `best_lung_cancer_model.pkl` (downloaded from Google Colab) in this same folder.
2. Open this folder in VS Code.
3. In the VS Code terminal run:
   `python -m pip install -r requirements.txt`
4. Run:
   `python -m streamlit run app.py`

## Important
This is an educational project based on a small survey dataset. The model output is not a medical diagnosis or validated estimate of cancer risk.

The app assumes the common dataset encoding: binary survey values 1 = No and 2 = Yes. Verify that this matches the encoding used when training your model.
